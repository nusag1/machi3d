# まち散歩3D

OpenStreetMap の地図データ（Overpass API）から、半径450mの建物・道・水辺・公園を3Dで立ち上げて歩きまわるページ。three.js r147（jsDelivr）。

- 最初の場所はみなとみらい。上の検索（Nominatim）で好きな場所へ。家などの場所はページに保存しない
- 建物の高さ：height → building:levels×3.3m → 種類ごとの目安
- 壁は窓の模様（夜は窓がランダムに光る）、屋根は三角形に分けて作る。全部まとめて少ないメッシュに
- 歩く：WASD／矢印、Shift で走る、ドラッグで見まわす、F で空から。スマホは左下のスティック
- 建物には入れない（点が多角形の中か、で判定。25mのマス目で近くの建物だけ見る）。「通りぬけ」で切りかえ
- 地図データ © OpenStreetMap contributors（ODbL）
